# RoboCode

Қазақ тіліндегі браузерлік оқу ойыны. HTML, CSS және JavaScript; сыртқы кітапханалар, аккаунттар және серверлік дерекқор жоқ.

## Іске қосу

Жоба бумасында:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

Браузерде `http://localhost:8765` мекенжайын ашыңыз. `index.html` файлын тікелей ашқанда ойын жұмыс істейді, бірақ PWA мен офлайн кэш қолжетімсіз.

Офлайн ойнау үшін localhost не HTTPS арқылы бір рет ашып, мәзірдегі «Офлайн ойнауға дайын» хабарын күтіңіз. Содан кейін сол мекенжайды желісіз ашуға болады. Орнату мүмкіндігі браузерге байланысты. `localhost` пен `127.0.0.1` — сақтау орны бөлек екі мекенжай; біреуін тұрақты қолданыңыз.

## Ойын

- Сайт бірден басты мәзірден ашылады. Профиль міндетті емес; жаңа ойыншы — «Дос». Бұрынғы профиль өзгертілмей оқылады. Атын өзгерту, дыбысты өшіру және мұғалім бөлімі «Баптаулар» ішінде.
- Төрт лабиринт — бір «Лабиринт» тарауы. Әр жаңа аяқталған тапсырма (саяхат пен түзету тапсырмасын қоса) бір рет 10 XP береді. Қайта ойнау бірінші сыйлықты қайталамайды.
- Сегіз жетістік бар: алғашқы деңгей, лабиринт тарауы, кемінде алты орындалған қадаммен жеңу, қатені түзету, барлық 13 негізгі деңгей және саяхаттың үш ауылы. Шарттары «Жетістіктер» экранында жазылған.
- Тарау алғаш толық аяқталғанда прогресс пен жетістік сақталып, құттықтау экраны ашылады. Ол өздігінен жабылмайды. Бұрын аяқталған тараулар көшіріліп есептеледі, құттықтау қайта көрсетілмейді.
- «Робидің саяхаты»: үш ауыл, тоғыз тапсырма, реттілік → қайталау → шарт. Әр тапсырма келесісін ашады.
- «Қайтала» және «Құдыққа жеткенше» карточкаларының ішіне әрекеттер қосылады. Бір қабат қайталау қолданылады; кірістірілген циклдер жоқ.
- «Егер тас болса» — тас барда секіру, әйтпесе қадам жасау ережесі. Бұл нұсқада шарттың тармақтары дайын.
- Қадам тек оңға жүреді; секіру екі торкөзге жылжытады. Тасқа немесе шетке тірелгенде орындау тоқтайды. Бағдарлама соңында робот құдықта тұруы керек.
- Соңғы тапсырмада сол бағдарлама жаңа жолда тексеріледі. Екі сәтсіз әрекеттен кейін бұл жол тапсырманы қайта ашқанда да көрінеді.
- Пауза, бір қадам, жылдамдық, орындалған қадамдарды қарау және соңғы 40 өңдеуді болдырмау бар. Қадамдар жолағын қарау жаңа жеңіс болып саналмайды.
- «Еркін ойын»: бұрынғы төрт лабиринт және «Қате команданы түзету». Лабиринтте бұрынғы ереже сақталған: мақсатқа жеткенде орындау бірден аяқталады.
- «Мұғалім бөлімі»: сабақ үлгісі, басып шығарылатын тапсырма, саяхаттың сақтау коды. Бұрынғы профильдегі сынып мәні контентті автоматты өзгертпейді.

Лабиринт пен саяхаттың белсенді ойын экрандары viewport биіктігімен шектеледі. Командалар мен қосымша ақпарат жеке айналады; мәзір мен баптаулар еркін айналады. Дыбыстар Web Audio API арқылы пайдаланушы әрекетінен кейін ғана жасалады. Қозғалысты азайту жүйелік баптауы ескеріледі.

## Сақтау

Барлығы тек осы браузерде сақталады:

| Кілт | Деректер |
| --- | --- |
| `robocode-player` | Бұрынғы профиль |
| `robocode-maze-progress` | Бұрынғы лабиринт прогресі, `version: 1` |
| `robocode-journey` | Жаңа саяхат: `version: 1`, `completed`, `verified`, `drafts`, `examFailures` |
| `robocode-rewards` | `version: 1`, тұрақты тапсырма ID-лері, жетістіктер, тараулар, ұзақ бағдарлама белгісі және ескі XP негізі |
| `robocode-sound` | `on` / `off` |

Сақтау коды тек саяхатты қамтиды; профиль, лабиринт және жетістіктердің бөлек деректері оған кірмейді. Импорт өткен тапсырмаларды біріктіреді, бар бағдарламаларды ауыстырмайды. Аяқталған деңгейлерден есептелетін XP мен белгілер қалпына келеді; түзету және ұзақ бағдарламамен жеңу белгілері кодтан тасымалданбайды. Қате немесе белгісіз нұсқадағы деректер үнсіз өшірілмейді. Прогресті тазарту тек баптаулардағы жеке растаудан кейін орындалады; профиль мен дыбыс таңдауы сақталады.

## Тексеру

Node.js арқылы, тәуелділіктер орнатпай:

```sh
node --test tests/*.test.cjs
node --check js/journey-core.js
node --check js/journey-content.js
node --check js/journey-progress.js
node --check js/journey.js
node --check js/main.js
node --check js/maze.js
node --check js/rewards.js
node --check js/feedback.js
node --check js/offline.js
node --check sw.js
git diff --check
```

Қолмен тексеру: жаңа профиль → тоғыз тапсырма → жаңа ауылдағы тексеру → финал; сақтау мен қайта ашу; орындау кезінде шығу; тоқтату; қадамдар жолағы; резервтік код; бұрынғы лабиринт; желіні өшіріп қайта жүктеу; сабақ бетін басып шығару.

PWA кэшінің файлдар тізімі `sw.js` ішінде. Жаңа нұсқаны жариялағанда `CACHE` атауын өзгертіңіз және жаңа файлдарды `FILES` тізіміне қосыңыз. Жаңарту дайын болғанда RoboCode қойындыларын жауып, қайта ашыңыз. Әзірлеу кезінде браузер құралдарынан service worker-ді өшіруге болады; localStorage-ті тазартудың қажеті жоқ.

Балалармен оқу тиімділігі, шынайы телефондағы орнату және Safari жұмысы бөлек тексеруді қажет етеді. Жазылған қазақша озвучка, еркін шарт редакторы, процедуралар және шығармашылық шеберхана бұл нұсқаға кірмейді.
